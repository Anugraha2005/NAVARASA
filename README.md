# Navarasa_data
This repository contains two folders: DATASET_NAVARASA and NAVARASA_AUGMENTED
These folders consist of the dataset of facial emotions in Indian classical dance.
Indian classical dance encompasses nine distinctive facial expressions, collectively called the Navarasas (nine emotions). These include Shringara (love), Haasya (humour and laughter), Karuna (compassion), Roudra (anger), Veera (heroism), Bhayaanaka (fearful terror), Bheebatsa (disgust), Adbhuta (wonder), and Shanta (peacefulness).
DATASET_NAVARASA consists of the frames extracted from the performance videos of around 30 performers.
NAVARASA_AUGMENTED consists of augmented images along with the original frames.
